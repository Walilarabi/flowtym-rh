# Registre des décisions du pilote — Flowtym RH

Consigner **toute décision** prise pendant le pilote (activation, ajustement de
périmètre, arbitrage, report). Une décision engageante ne doit exister que si elle
figure ici. Ne modifie ni le code ni les flags sans une ligne correspondante.

## Convention
- **Impact** : Faible / Moyen / Élevé. **Validation** : qui approuve (Release Manager,
  Produit, Paie…). **Suivi** : action de suivi + échéance.

| Date | Décision | Contexte | Auteur | Impact | Validation | Suivi |
|---|---|---|---|---|---|---|
| | | | | | | |
