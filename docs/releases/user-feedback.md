# Registre des retours utilisateurs — pilote Flowtym RH

Recueillir et **classer** les retours pour alimenter les futures User Stories (RC2).
Chaque retour doit pouvoir être relié à une US et, si besoin, à un incident.

## Catégories
`Bug` · `UX` · `Performance` · `Fonction manquante` · `Compréhension` (le produit
n'est pas clair) · `Suggestion`.

## Convention
- **Priorité ressentie** : Élevée / Moyenne / Faible (perçue par l'utilisateur).
- **US liée** : identifiant de User Story future (RC2) ou « à créer ».
- **Incident lié** : id dans `pilot-incidents.md` si applicable.
